Usage

SuperCompress is a hosted API. Call it with curl, the Python client, or supercompress setup for coding agents. Neural Keep runs on the service.

Options

  1. Hosted API (recommended)
  2. Python client
  3. Which to choose?

Hosted API (recommended)

The fastest way to use SuperCompress in production. Get an API key, call the endpoint, done. No servers, no containers, no config.

Get a key

Sign in at supercompress.dev/dashboard with Google or email and create an API key. A free monthly allowance is included.

Call the API

# Quick one-liner (form-encoded)
curl -d "context=Your long context...&query=What do you want to know?" \
  https://supercompress.dev/compress \
  -H "X-API-Key: sc_live_YOUR_KEY"

# Or as JSON (standard)
curl -X POST https://supercompress.dev/api/v1/compress \
  -H "X-API-Key: sc_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"context":"Your long context here…","query":"What do you want to know?"}'

# Prefer header auth, query-string API keys are rejected
curl -X POST https://api.supercompress.dev/compress \
  -H "X-API-Key: sc_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"context":"…","query":"…"}'

Python client

from supercompress.client import SuperCompress

sc = SuperCompress()  # reads SUPERCOMPRESS_API_KEY
out = sc.compress(context, question)
print(out.compressed_text)

Set your key as an environment variable:

export SUPERCOMPRESS_API_KEY=sc_live_YOUR_KEY

Python client

The Python package is a client for the hosted Neural Keep API. Neural Keep runs on the service, not on your machines. Set SUPERCOMPRESS_API_KEY and call compress from your app.

Install

pip install supercompress

Use it

from supercompress.client import SuperCompress

sc = SuperCompress()  # reads SUPERCOMPRESS_API_KEY
result = sc.compress(
    context="Your long context…",
    query="What does fetch return?",
)

print(result.compressed_text)
print(f"Saved {result.tokens_saved_pct:.1f}% tokens")

Browser / static sites

The playground at supercompress.dev/playground can preview a local compiler path in the browser. Production quality is hosted Neural Keep via the API.
