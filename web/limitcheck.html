Use the whole window.

Coding agents stop at about 90% of their 5-hour limit to be safe. Then the window resets and the last 10% expires unused. limitcheck tells the agent how much quota is really left, so it keeps working to the end and checkpoints before the cutoff. In 60 simulated heavy 5-hour windows it used 100% of each window instead of 91.5%: 7.8% more work done.
