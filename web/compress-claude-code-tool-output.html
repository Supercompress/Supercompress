Compress Claude Code tool output with hooks and MCP

By Arjun Shah

To compress Claude Code tool output, run npm install -g supercompress-proxy then supercompress setup. Setup adds an MCP server, instructions and UserPromptSubmit and PostToolUse hooks. After large tool calls, the hook sends the output and your request to the hosted SuperCompress model and passes the kept lines to Claude.

Why target tool output in Claude Code?

In a typical coding session the bulk of tokens are inputs the model re-reads: file reads, test runs, grep results and build logs. Shorter replies help a little, but the large lever is what Claude reads. A failing test run may be thousands of lines where a few lines explain the failure.

How do I install it?

  1. Install and link your account. Setup opens your browser to sign in; no API key step is needed for coding agents.
    npm install -g supercompress-proxy && supercompress setup
  2. Confirm detection with supercompress agents and health with supercompress doctor.
  3. Restart Claude Code so the MCP server loads.

What does setup change?

  • MCP server in ~/.claude.json exposing compress_context, connect_account and usage_summary.
  • Hooks in ~/.claude/settings.json: UserPromptSubmit and PostToolUse.
  • Instructions in CLAUDE.md telling Claude when to call the tool.

It does not change how Claude Code talks to Anthropic, so your normal login keeps working.

How do I check that it is working?

Run a command with large output, such as a full test suite, and watch for the compressed context. The usage_summary tool and your dashboard show per-agent requests and tokens in and out. The API reports original_tokens and kept_tokens per call.

What else reduces Claude Code token costs?

  • /clear between tasks and steered /compact within one, see compact vs clear vs compression.
  • Keep CLAUDE.md short.
  • Disconnect MCP servers you do not need, see MCP context bloat.

How do I remove it?

Run supercompress uninstall. It removes only the entries SuperCompress added and restores backed-up configs.

Frequently asked questions

How do I reduce Claude Code token costs?

Clear between tasks, keep CLAUDE.md small, prune MCP servers, and compress bulky tool output against your request with a PostToolUse hook.

Does SuperCompress need an Anthropic API key?

No. It works alongside your normal Claude Code login and does not proxy your Anthropic traffic.

Do I need a SuperCompress API key for Claude Code?

No. supercompress setup signs you in through a browser link and saves a coding agent key automatically.

Where is my context processed?

Hosted requests are processed by SuperCompress's hosted model service.
