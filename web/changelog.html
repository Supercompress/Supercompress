0.5.7 2026-08-01 proxy

Coding agent plugin

  • Auto across agents: MCP installed on every detected host (Cursor, Claude, Codex, OpenCode, FreeBuff, Windsurf, Continue, Gemini, and more).
  • Claude Code + Codex: every-message + PostToolUse tool-dump compression.
  • Always-on instruction files when those agents are present.

Coding agent plugin

  • Every-message auto-compress: IDE beforeSubmitPrompt writes ~/.supercompress/inbox/latest.md on every submit; Claude Code + Codex UserPromptSubmit inject compressed digests; postToolUse threshold lowered to 800 chars.
