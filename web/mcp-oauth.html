New OAuth MCP

SuperCompress MCP now has OAuth

One URL. Sign in with Google when your client asks. No API key to dig out of the dashboard, no env var to paste, no restart ritual just to try compression.

October 1, 2026 · Launch note

MCP overview Coding agents v2 launch Benchmarks Changelog Blog

Until now, connecting SuperCompress to your coding agent meant digging an API key out of the dashboard, finding the right config file, pasting it in, and restarting. That is way too much friction just to try a tool.

Now it is one URL. Add https://www.supercompress.dev/api/mcp to any MCP client that supports OAuth, sign in with Google when it asks, and you are connected. No key to copy, no env var to set.

Why it matters

The logs, diffs, and huge file reads your agent pulls in go through our hosted ~400M Neural Keep model before they hit the context window. It keeps the lines that actually answer the question, in their original wording, and drops the noise. Your agent stays sharp and your sessions last longer.
