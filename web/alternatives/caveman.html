Caveman alternative: SuperCompress

Caveman is an open-source skill and local CLI that makes coding agents answer in fewer words and shrinks some tool output before the model reads it. SuperCompress is a different kind of tool: it targets the input side, sending bulky context and the current question to a hosted Neural Keep model that keeps only the original lines that answer it. If your cost comes from what the agent reads rather than what it writes, SuperCompress is the alternative to try.

What Caveman is

Caveman (Apache-2.0) started as a Claude Code skill that tells the agent to reply in short, caveman-style sentences while leaving code exact. It has grown into a CLI (@caveman-ai/cli) with several parts: shorter replies, a local proxy that shrinks logs, JSON, test output and web pages before the model reads them, and middleware for apps you build. Its local tools run on your machine with your own provider keys. Sources: Caveman on GitHub, caveman.so, Caveman docs.

One thing worth knowing: shorter replies cut output tokens, but in long agent sessions most tokens are input, meaning the files, logs and history the model rereads every turn. Caveman's own site says the output style alone is not a large cost saving on long coding tasks, which is why its newer versions also compress input.

How SuperCompress works

SuperCompress is hosted, query-aware context compression. Your agent or app sends a bulky block of context (a log, a diff, a long file read, an MCP result, retrieved documents) together with the question being asked. The hosted API keeps the original lines that answer that question, word for word, and drops the rest. Nothing is paraphrased, so error messages, file paths, IDs and code come through exactly as they were.

Coding agents reach it through an MCP tool (compress_context) plus hooks that the setup command installs where the agent supports them. Apps reach it through POST /api/v1/compress, which returns the kept text along with original_tokens and kept_tokens so you can see what changed on your own traffic. See the benchmarks page for the published methodology.

When Caveman is the better fit

If you mostly want terser answers in chat, or you need every part of the toolchain to stay on your machine, Caveman is a reasonable choice and the skill alone is very light.

When SuperCompress is the better fit

If your agent keeps reading huge outputs where only a handful of lines matter, such as a failing test run, a long stack trace, a big JSON response from an MCP server, or a long file, SuperCompress addresses that directly by keeping the lines that answer the question and dropping the rest. It also leaves the agent's normal voice alone, which some teams prefer for code review and explanations.

How to pick fairly

Every tool in this space publishes its own headline numbers, and independent studies have found that fewer tokens do not always mean a smaller bill once prompt caching, retries and extra agent turns are counted. (see PointFive's end-to-end study, the code-compression-bench SWE-bench runs, JetBrains' rtk trial and the THOL leaderboard; none of them tested SuperCompress) Run the same tasks with and without a tool, check that the tasks still succeed, and compare your provider bill per finished task. That test matters more than any vendor page, including this one.

Try it

One command installs the CLI and wires the hosted compressor into every coding agent it finds on your machine (Claude Code, Cursor, Codex, Windsurf, Cline, Gemini CLI, OpenCode and more). Then supercompress doctor shows a health check per agent.

npm install -g supercompress-proxy && supercompress setup

Building your own app instead? Call the hosted API with a key from the dashboard.

FAQ

What is the best Caveman alternative?

If you want to cut what your coding agent reads rather than how it talks, SuperCompress is a strong alternative. It keeps the original input lines that answer the current question using a hosted, query-aware model.

What does Caveman do?

Caveman is an open-source skill and CLI that makes AI agents reply in fewer words and, in newer versions, shrinks logs, JSON and other tool output locally before the model reads them.

Does SuperCompress make the agent talk differently?

No. SuperCompress only compresses input context. The agent's replies are unchanged.

Can I use Caveman and SuperCompress together?

Caveman's reply style skill and SuperCompress act on different sides of the conversation, so they can be combined. Avoid stacking two input compressors on the same content without testing.

Is Caveman free?

The Caveman skill and local CLI are free and open source under Apache-2.0. Caveman Cloud is a separate hosted product for teams.
