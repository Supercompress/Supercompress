# Design context — SuperCompress Control Plane ops UI

Confidential until launch. Not a public marketing surface.

## Users & purpose

- **Who**: Arjun + future enterprise ops / platform eng evaluating AI gateway spend
- **Job**: Prove compress-then-route economics in one glance — what LiteLLM cannot show
- **Emotion**: Calm confidence, industrial precision, “we already won on the math”

## Brand personality

Precise · paper-forward · quietly aggressive on the moat

## Visual direction

- SuperCompress product tokens: paper `#fbfbf8`, ink near `#0b1220`, brand `#0566ff`
- Display: Platypi (serif). Body: Source Sans 3 — not Inter/system defaults
- Light mode primary. No purple glow, no neon-on-dark, no generic SaaS card grids
- One hero composition: brand + moat headline + $ delta. Detail below, not competing

## Anti-references

LiteLLM admin clutter, Datadog density, purple AI dashboards, emoji-heavy ops UIs

## Constraints

- Lives under `services/gateway/ops-ui/` + private mirror; served only when `SC_CP_OPS=1`
- Never show asks/prompts — Compression Trace sizes + spend only
- Demo mode must work offline with synthetic but honest economics math
