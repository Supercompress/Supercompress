# SuperCompress AI

CLI entry for SuperCompress. Same setup command as the core package:

```bash
npx -y supercompress-ai setup
```

That links your account and installs MCP plus hooks on detected coding agents.

```bash
# equivalent long form
npx -y -p supercompress-ai supercompress setup
npm install -g supercompress-proxy && supercompress setup
```

- Website: https://www.supercompress.dev
- Docs: https://docs.supercompress.dev/coding-agents
- Core package: [`supercompress-proxy`](https://www.npmjs.com/package/supercompress-proxy)
